# Scientific Calculator (C# / .NET)

Acesta este un proiect dezvoltat în cadrul facultății (Anul 2) care implementează un calculator de expresii matematice, punând accent pe principiile **Programării Orientate pe Obiect (OOP)**.

## 🚀 Funcționalități
* Evaluarea expresiilor matematice complexe.
* Suport pentru operații de bază și funcții științifice.
* Arhitectură modulară bazată pe clase.

## 🛠️ Concepte Tehnice Aplicate
* **Încapsulare și Moștenire:** Utilizate pentru a gestiona tipurile diferite de operatori și operanzi.
* **Separarea Responsabilităților:** Codul este structurat pentru a separa logica de calcul de interfața cu utilizatorul.
* **Versionare:** Gestionarea codului utilizând Git și GitHub.

## 📂 Structura Proiectului
* `MathExpressions.Core`: Biblioteca care conține logica de parsare și calcul.
* `MathExpressionsSolution`: Soluția principală Visual Studio.
